# Tic-Tac-Toe Game 🎮

This is my first JavaScript project where I created a simple Tic-Tac-Toe game using HTML, CSS, and JavaScript.

## About Project

Tic-Tac-Toe is a two-player game where players take turns placing X and O on a 3×3 board. The game checks the winner and shows the result.

## Features

- Player X and Player O turns
- Winner detection
- Draw detection
- Reset game button
- Simple user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

While making this project, I learned:

- How to use JavaScript DOM
- How to handle button click events
- How to update HTML using JavaScript
- Basic game logic

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing the game.
